# PRICING LOGIC — NoTime Storage (MONTHLY)

Box pricing (per box, per month):
- 1 box → $80
- 2 boxes → $55 per box
- 3 boxes → $55 per box
- 4 boxes → $60 per box

Item pricing (per item, per month):
- Small item with box → $9
- Medium item with box → $9
- Small item without box → $11
- Medium item without box → $12
- Large item (with or without box) → $15

Pricing intent:
- Pricing should remain configurable
- Structure should allow future changes and expansion
