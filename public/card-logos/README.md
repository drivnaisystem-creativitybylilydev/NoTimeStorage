# Card network logos (checkout payment section)

Put the **4 logo image files** here. The app will scale them to fit; any size is fine.

## Files to add

| Company            | Filename to use   |
|--------------------|-------------------|
| **Visa**           | `visa.jpg` |
| **Mastercard**     | `mastercard.jpg` |
| **American Express** | `amex.jpg` |
| **Discover**       | `discover.jpg` |

The code looks for **`.jpg`** files. PNG or SVG is fine too—use `visa.png` / `visa.svg` etc. and we can switch the component to that extension.

They will be displayed at about 40×28px each; the code fits them inside that area, so large or small images both work.
